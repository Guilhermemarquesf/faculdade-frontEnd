- Breve descrição sobre seu projeto: A página possui uma estrutura organizada com:

Cabeçalho (header) contendo o nome do site e um menu de navegação;
Seção principal com título e uma área de busca;
Seção de conteúdo (grid) exibindo cards de clubes, cada um com imagem, nome e descrição;
Seção de contato, com informações básicas;
Rodapé (footer) com dados institucionais.

A responsividade foi implementada com media queries, flexbox, permitindo que o layout se adapte para diferentes dispositivos, exibindo os conteúdos em múltiplas colunas no desktop e em uma única coluna no mobile.

O projeto também segue um processo de desenvolvimento versionado com Git e GitHub, registrando as etapas por meio de commits e tag de versão.
