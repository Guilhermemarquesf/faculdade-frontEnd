# Alternador de Tema (Dark/Light Mode) 🌗

Este é um projeto simples desenvolvido para praticar os fundamentos de **JavaScript, HTML e CSS**. O objetivo principal é manipular o DOM (Document Object Model) para alternar a cor de fundo da página entre os modos claro (branco) e escuro (preto) através do clique de um botão.

## 🚀 Funcionalidades
* ✅ Interface simples com um botão de ação.
* ✅ Evento de clique (Event Listener) usando JavaScript.
* ✅ Alteração dinâmica de classes CSS ou estilos inline.
* ✅ Transição suave entre os temas escuro e claro.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura da página e do botão.
* **CSS3:** Estilização visual e cores de fundo.
* **JavaScript (Vanilla):** Lógica de troca de tema e interação do usuário.
